## 📚 주요 콘텐츠

### 1. 자기소개와 대학 생활

소프트웨어를 공부하면서 중요하게 생각하게 된 **동작 원리에 대한 이해, 직접 구현해 보는 경험, 오류를 점검하는 태도**를 소개합니다. 대학 입학 전의 관심에서 시작해 수업과 실습을 거쳐 현재의 학습 방식으로 이어진 과정을 기록했습니다.

### 2. 중점 전공 — 운영체제 (Operating Systems)

컴퓨터가 여러 프로그램과 시스템 자원을 어떻게 관리하는지 학습한 내용을 중심으로 소개합니다.

- **프로세스와 스레드:** 실행 단위, 상태, 자원 공유
- **CPU 스케줄링:** 준비 큐, 라운드 로빈, 시간 할당
- **메모리 관리:** 페이징, 페이지 테이블, 논리·물리 주소 변환, TLB
- **동기화:** 공유 자원 접근과 경쟁 조건

특히 CPU·I/O 실행 흐름을 도표로 따라가거나, 페이지 테이블과 TLB를 이용한 주소 변환 과정을 단계별로 분석했던 학습 기록을 담았습니다.

### 3. 중점 전공 — 지능형 시스템 (Intelligent Systems)

데이터가 어떻게 처리되고 학습 모델이 어떤 구조로 동작하는지 이해하기 위한 학습 내용을 정리했습니다.

- **인공신경망:** 입력층·은닉층·출력층과 가중치
- **CNN:** 합성곱을 이용한 특징 추출 원리
- **LSTM:** 순서가 있는 데이터를 다루는 모델 구조와 게이트의 역할

이 영역은 **모델의 개념과 원리를 공부한 기록**이며, 별도의 AI 서비스 개발 성과나 모델 학습 실적으로 표현하지 않았습니다.

### 4. 전공 실습 및 과제

| 실습 | 사용 기술 | 핵심 학습 내용 |
|---|---|---|
| 산수 문제 웹페이지 | HTML, CSS, JavaScript | DOM, 이벤트 처리, 화면 초기화와 문제 생성 로직 |
| 차량 클래스 계층 구조 설계 | Java | 추상 클래스, 상속, 인터페이스 |
| BFS 그래프 탐색 | Python | 큐, 그래프의 연결 방향, 방문 상태 관리 |
| 숫자 버튼 GUI | Java Swing | 이벤트 처리, 버튼 교환, 색상 및 UI 상태 관리 |

운영체제와 지능형 시스템 외에도 웹 프로그래밍, 알고리즘, 컴퓨터 구조, 어셈블리어, 디지털 논리회로 등 여러 전공 과목에서 배운 내용을 함께 소개합니다.

### 5. 개인적인 관심과 성찰

- **취미:** 게임과 소설
- **학습 과정:** 이해 → 구현 → 점검 → 기록
- **변화와 성찰:** 정답만 확인하기보다 프로그램이 그렇게 동작하는 이유를 살펴보는 태도
- **향후 목표:** 운영체제 기초를 더 깊이 이해하고, 지능형 모델의 구조를 탐구하며, 직접 구현하는 경험을 늘리기

## ✨ 웹 앱 주요 기능

- **반응형 웹 디자인:** PC, 태블릿, 스마트폰 화면에 맞춰 레이아웃 변경
- **다크 모드:** 테마 전환 기능
- **학습 분야 필터:** 운영체제, 지능형 시스템, 기타 개발 학습 내용 분류
- **프로젝트 상세 설명:** 실습별로 추가 설명을 펼쳐서 확인
- **발표 모드:** 교수님 앞에서 보여줄 수 있는 8장 구성 슬라이드
- **슬라이드 키보드 조작:** `←` / `→`로 이동하고 `Esc`로 종료
- **프로필 사진:** 메인 화면에서 사진과 자기소개 표시

## 🛠️ 사용 기술

| 기술 | 역할 |
|---|---|
| HTML5 | 자기소개, 전공 학습, 프로젝트 및 발표 화면의 구조 |
| CSS3 | 다크 계열 디자인, 애니메이션, 반응형 레이아웃 |
| JavaScript | 메뉴, 학습 필터, 테마 전환, 발표 모드 등의 상호작용 |
| Google Apps Script | `doGet()`과 HTML Service를 이용한 웹 앱 제공 및 배포 |

별도의 외부 프론트엔드 프레임워크나 데이터베이스 없이 동작하는 **정적 콘텐츠 중심의 포트폴리오**입니다. 화면 스타일과 클라이언트 JavaScript는 `index.html`에 포함되어 있습니다.

## 🚀 Google Apps Script 배포 방법

1. Google Drive에서 새 Google Apps Script 프로젝트를 생성합니다.
2. `Code.gs`에 웹 앱 실행 코드를 작성합니다.
3. HTML 파일을 `index`라는 이름으로 추가하고 `index.html` 내용을 붙여넣습니다.
4. **배포 → 새 배포 → 웹 앱**을 선택합니다.
5. 필요한 실행 계정과 접근 권한을 설정한 후 배포합니다.
6. 발급된 웹 앱 URL로 접속하여 화면과 발표 모드를 확인합니다.

코드를 변경한 경우 기존 배포에 적용하려면 **배포 관리 → 기존 배포 수정 → 새 버전**으로 업데이트해야 합니다.
