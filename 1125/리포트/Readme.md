# ⚡ WATTMAP — 컴퓨터 파워서플라이 용량 계산기

**컴퓨터 부품을 선택하면 필요한 전력 예산을 계산하고, 적절한 파워서플라이(PSU)를 검토할 수 있는 Google Apps Script 웹 앱입니다.**

CPU와 GPU를 중심으로 메인보드, 메모리, 저장장치, 쿨러, 케이스 팬, 주변기기 등의 전력을 종합적으로 계산합니다. 선택한 파워서플라이의 **정격 출력·80 PLUS 효율 등급·물리적 규격·모듈러 방식**을 비교하고, 견적을 Google Sheets에 저장해 다시 불러오거나 비밀 관리키로 삭제할 수 있습니다.

웹 프로그래밍 실습 프로젝트 **#3**으로, 부품 사양 데이터와 사용자 견적 데이터를 각각 다른 스프레드시트에 저장합니다.

## 🎯 제작 목적

컴퓨터를 새로 조립할 때 각 부품을 고르는 것만큼 어려운 부분이 **필요한 파워서플라이 용량을 판단하는 일**입니다. CPU와 GPU는 전력 소모 차이가 크고, 메모리·저장장치·추가 장치에 따른 부하도 고려해야 합니다.

WATTMAP은 사용자가 고른 부품을 바탕으로 **PC 내부 전력 예산과 추천 PSU 정격을 계산**하고, 선택한 파워서플라이의 조건을 한 화면에서 점검하도록 돕기 위해 제작했습니다.

## ✨ 주요 기능

- **0W 초기 상태:** 처음 접속했을 때 부품이 선택되어 있지 않으며, 필요한 부품을 하나씩 추가합니다.
- **CPU·GPU 검색:** AMD·Intel CPU, NVIDIA·AMD·Intel GPU를 브랜드별로 조회하고 전력 기준·상대적 성능 등급을 표시합니다.
- **GPU 모니터 가이드:** 모델 포지션에 따라 QHD·4K 등의 권장 해상도와 주사율 목표를 참고용으로 안내합니다.
- **메인보드 규격 검토:** Mini-ITX, M-ATX, ATX, E-ATX의 특징을 비교하고 RAM·M.2·SATA·PCIe 수량에 맞춰 확장성을 안내합니다.
- **메모리 및 저장장치:** DDR4/DDR5, 모듈 용량·개수, SSD/HDD 및 쿨러·팬 수량을 반영합니다.
- **주변기기 통합 선택:** 모니터 해상도와 주사율, 키보드, 마우스, USB 기기 등을 종류·사양·수량으로 추가합니다.
- **별도 전원 구분:** 모니터처럼 콘센트에서 직접 전력을 공급받는 장치는 PC PSU 출력에 합산하지 않고 콘센트 전력 예산으로 구분합니다.
- **PSU 사양 검토:** 정격 W, 80 PLUS 등급, ATX/SFX/TFX, 비·세미·풀모듈러 방식의 특징과 적합성을 표시합니다.
- **견적 저장 및 복원:** CPU·GPU 모델과 모든 추가 부품 및 계산 결과를 Google Sheets에 저장한 뒤 조회코드로 불러옵니다.
- **본인 견적 삭제:** 저장할 때 별도로 발급되는 삭제 관리키만 입력하면 해당 견적 행을 제거합니다.

## 🔐 8자리 조회코드와 삭제 관리키

**v9부터 새로 저장하는 견적에는 서로 다른 8자리 영문 대문자·숫자 코드 두 개를 발급합니다.**

| 코드 | 역할 | 필요한 정보 |
|---|---|---|
| 조회코드 | 저장된 견적을 찾아 화면에 불러오기 | 조회코드 8자리 |
| 삭제 관리키 | 저장된 견적을 Google Sheets에서 영구 삭제 | **삭제 관리키 8자리만 입력** |

조회코드와 삭제 관리키는 서로 다르게 발급됩니다. **삭제할 때는 조회코드를 입력하지 않습니다.** 서버에서 삭제 관리키의 해시를 확인한 뒤 해당 행을 찾아 제거하므로, 중간 행을 삭제해도 아래의 기록이 위로 이동하고 새 견적은 이어서 저장됩니다.

신규 삭제키는 원문 대신 **HMAC-SHA256 결과**만 시트에 저장하고, 서버는 짧은 코드의 무작위 대입을 늦추기 위한 요청 횟수 제한을 적용합니다. 다만 8자리는 기존의 긴 비밀키보다 추측에 대한 여유가 적으며, 서버 호출 제한은 보조적인 보호 장치입니다. **이 방식은 Google 계정 소유자 인증이 아니라 비밀 관리키 소유 여부를 확인하는 방식**이므로 관리키를 타인에게 알려주면 해당 견적이 삭제될 수 있습니다.

이전 버전에서 발급한 **UUID 조회코드와 긴 `WM-...` 삭제 관리키도 계속 지원**합니다. 삭제 관리키가 발급되기 전의 기록은 관리자가 수동으로 처리해야 합니다.

## 📊 두 Google Sheets의 역할

| 구분 | 스프레드시트 | 주요 탭 |
|---|---|---|
| 사용자 데이터 저장 | 컴퓨터 파워 계산기 | `견적기록` — 상세 구성, 계산 결과, 비밀 관리키 해시 / `견적요약` — 주요 값 자동 표시 |
| 부품 데이터 조회 | WATTMAP 부품 사양 DB | `CPU`, `GPU`, `메인보드 규격` — 모델·전력 기준·특징·근거 링크 |

사용자가 고른 부품 정보는 웹 화면에서 계산되는 동시에 **GAS 서버에서 재검증**한 뒤 견적 기록 시트에 저장됩니다. 부품 사양은 별도 시트에서 읽어오므로, 새로운 모델을 등록하거나 수치를 검토할 때 저장된 견적과 분리해 관리할 수 있습니다.

## 🚀 Google Apps Script 적용 방법

1. 기존 WATTMAP Google Apps Script 프로젝트를 엽니다.
2. `Code.gs`, `index.html`에 최신 파일 내용을 붙여넣고 저장합니다.
3. 필요하다면 `setupProject()`와 `testConnection()`을 실행해 연결된 두 스프레드시트를 확인합니다.
4. **배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포**로 수정 사항을 반영합니다.
5. 웹 앱에서 테스트 견적을 저장하고 **8자리 조회코드와 8자리 삭제 관리키**가 발급되는지 확인합니다.
6. 조회코드로 복원하고, 삭제 관리키 하나로 행이 삭제되는지 확인합니다.

> 이미 저장된 견적과 기존 스프레드시트의 열 구조는 그대로 사용하도록 작성되어 있습니다. **업데이트만을 위해 기존 사용자 기록을 삭제하지 마세요.**

## ⚠️ 계산 결과의 한계

WATTMAP의 추천 W는 제조사 사양과 모델별 전력 예산, 앱에서 설정한 여유율을 이용한 **추정치**입니다. 메인보드·RAM 전력 예산과 성능 티어는 대표값 또는 편의상 분류이며, 실제 측정값이 아닙니다. PSU 구매 전에는 제조사 권장 출력, 순간 부하, 보조전원 커넥터, 케이스 장착 공간과 PSU 품질을 반드시 확인해야 합니다.
