# 9장 이벤트 기초 및 활용 — 시험 대비 학습 요약

## 1. 이벤트와 이벤트 리스너 (3~4쪽)

| 용어          | 뜻                                              | 예시                             |
| ------------- | ----------------------------------------------- | -------------------------------- |
| 이벤트        | 사용자 입력 또는 브라우저 상태 변화에 대한 알림 | `click`, `keydown`, `load`       |
| 이벤트 리스너 | 이벤트를 처리하는 함수·코드                     | `onclick`, `onkeydown`, `onload` |
| 이벤트 타깃   | 이벤트를 일으킨 DOM 객체                        | 클릭한 버튼                      |
| 이벤트 객체   | 발생 이벤트의 상세 정보                         | 마우스 좌표, 눌린 키             |

**이름 구분:** `click`은 이벤트 이름이고 `onclick`은 이벤트 리스너 프로퍼티/HTML 속성 이름이다. `addEventListener()`에는 **`"click"`**처럼 `on`을 제외한 이벤트 이름을 전달한다.

### 자주 나오는 이벤트

| 이벤트 / 리스너                 | 발생 시점                  |
| ------------------------------- | -------------------------- |
| `click` / `onclick`             | 요소 클릭                  |
| `dblclick` / `ondblclick`       | 더블클릭                   |
| `mousedown` / `onmousedown`     | 마우스 버튼 누름           |
| `mouseup` / `onmouseup`         | 마우스 버튼 놓음           |
| `mouseover` / `onmouseover`     | 포인터가 요소 위로 들어옴  |
| `mouseout` / `onmouseout`       | 포인터가 요소에서 나감     |
| `mousemove` / `onmousemove`     | 포인터 이동                |
| `wheel` / `onwheel`             | 휠 조작                    |
| `keydown` / `onkeydown`         | 키 누름                    |
| `keyup` / `onkeyup`             | 키 놓음                    |
| `load` / `onload`               | 문서 또는 이미지 로딩 완료 |
| `change` / `onchange`           | 폼 값·선택 변경            |
| `focus` / `onfocus`             | 포커스를 얻음              |
| `blur` / `onblur`               | 포커스를 잃음              |
| `submit` / `onsubmit`           | 폼 제출                    |
| `reset` / `onreset`             | 폼 초기화                  |
| `contextmenu` / `oncontextmenu` | 오른쪽 클릭 메뉴 요청      |

## 2. ★ 이벤트 리스너 등록 3가지

### ① HTML 태그 속성에 직접 작성

```html
<p
  onmouseover="this.style.backgroundColor='orchid'"
  onmouseout="this.style.backgroundColor='white'"
>
  마우스를 올려 보세요
</p>
```

- `this`: 해당 리스너가 붙은 요소를 가리킴.
- `style.backgroundColor`: CSS 배경색을 JavaScript에서 변경.

### ② DOM 객체의 이벤트 리스너 프로퍼티에 등록

```html
<p id="p">마우스를 올려 보세요</p>
<script>
  function over() {
    document.getElementById("p").style.backgroundColor = "orchid";
  }
  let p = document.getElementById("p");
  p.onmouseover = over; // 함수 자체를 등록
</script>
```

**★ `p.onmouseover = over;` (정답) / `p.onmouseover = over();` (잘못된 등록)**. 뒤의 코드는 등록할 때 함수를 실행해 버린다.

### ③ `addEventListener()`로 등록

```javascript
let p = document.getElementById("p");
p.addEventListener("mouseover", over);
p.addEventListener("mouseout", function () {
  this.style.backgroundColor = "white";
});
```

**형식:** `객체.addEventListener(eventName, listener, useCapture)`

| 인수         | 의미                                              |
| ------------ | ------------------------------------------------- |
| `eventName`  | `"click"`, `"mouseover"` 등. **on 없음**          |
| `listener`   | 실행할 함수의 이름 또는 함수 자체                 |
| `useCapture` | `true` = 캡처 단계, `false` 또는 생략 = 버블 단계 |

**익명 함수(anonymous function)**: 함수 이름 없이 필요한 자리에 바로 작성. 짧거나 한 번만 쓰는 처리에 적합.

```javascript
p.onmouseover = function () {
  this.style.backgroundColor = "orchid";
};
```

**비교:** HTML `onclick="f()"` / 프로퍼티 `obj.onclick = f` / 메소드 `obj.addEventListener("click", f)`.

## 3. ★ 이벤트 객체 `event` / `e`

이벤트가 발생하면 브라우저가 이벤트 관련 정보를 담은 객체를 리스너에 전달한다.

```javascript
function f(e) {
  alert(e.type);
}
obj.onclick = f;
```

HTML 속성에서 넘길 때:

```html
<button onclick="f(event)">클릭</button>
```

| 속성·메소드           | 반드시 외울 의미                         |
| --------------------- | ---------------------------------------- |
| `e.type`              | 이벤트 종류 (`"click"` 등)               |
| `e.target`            | **실제로 이벤트를 발생시킨 요소**        |
| `e.currentTarget`     | **현재 리스너가 실행 중인 요소**         |
| `e.defaultPrevented`  | 기본 동작 취소 여부 (`true`/`false`)     |
| `e.cancelable`        | 기본 동작을 취소할 수 있는지             |
| `e.preventDefault()`  | 링크 이동, 폼 전송 등 **기본 동작 취소** |
| `e.stopPropagation()` | 이벤트의 **전파 중단**                   |

### ★ `target`과 `currentTarget` 차이

부모 `<div>`에 클릭 리스너가 있고 그 안의 `<button>`을 누른 경우:

- `e.target` = 실제 클릭한 **button**
- 부모 리스너 실행 중 `e.currentTarget` = 리스너가 붙은 **div**

### 기본 동작(default action) 취소

```html
<a href="https://example.com" onclick="return false">이동하지 않음</a>
<a href="https://example.com" onclick="event.preventDefault()">이동하지 않음</a>
```

- 링크의 기본 동작: 이동
- submit 버튼의 기본 동작: 폼 전송
- 체크박스 클릭의 기본 동작: 체크 상태 변경
- **주의:** `preventDefault()`는 취소 가능한 이벤트(`cancelable`)에 대해서만 효과가 있다.
- **주의:** `stopPropagation()`은 전파를 막는 것이지 기본 동작 자체를 취소하는 것은 아니다.

## 4. ★ 이벤트 흐름: 캡처링과 버블링

```text
window
  ↓  캡처(capturing)
document → html → body → 부모 요소
  ↓
이벤트 타깃 (예: button)
  ↑
부모 요소 → body → html → document → window
     버블(bubbling)
```

| 구분      | 캡처 단계                            | 버블 단계                             |
| --------- | ------------------------------------ | ------------------------------------- |
| 방향      | 상위 → 하위(타깃)                    | 타깃 → 상위                           |
| 등록      | `addEventListener("click", f, true)` | `addEventListener("click", f, false)` |
| 기본 설정 | 명시적으로 `true` 지정               | 세 번째 인수 생략 시 기본값           |

```javascript
document.body.addEventListener("click", capture, true);
button.addEventListener("click", bubble, false);
document.body.addEventListener("click", bubble, false);
```

**교재 예제 9-8에서 버튼 클릭 시 실행 순서**

1. `body`의 캡처 리스너
2. `button`의 리스너
3. `body`의 버블 리스너

```javascript
function capture(e) {
  console.log("capture", e.currentTarget.tagName);
}
function bubble(e) {
  console.log("bubble", e.currentTarget.tagName);
}
```

**흐름 중단:** `e.stopPropagation();`

## 5. 마우스 이벤트와 좌표

### 주요 마우스 이벤트

| 리스너          | 기억할 동작                                            |
| --------------- | ------------------------------------------------------ |
| `onclick`       | 클릭                                                   |
| `ondblclick`    | 더블클릭                                               |
| `onmousedown`   | 누르는 순간                                            |
| `onmouseup`     | 놓는 순간                                              |
| `onmouseover`   | 요소 위에 진입, 자식 요소 경계에서도 관련 이벤트 가능  |
| `onmouseout`    | 요소에서 벗어남, 자식 요소 경계에서도 관련 이벤트 가능 |
| `onmouseenter`  | 요소에 진입, 버블링 없음                               |
| `onmouseleave`  | 요소에서 벗어남, 버블링 없음                           |
| `onmousemove`   | 마우스 이동 중                                         |
| `onwheel`       | 휠 회전                                                |
| `oncontextmenu` | 오른쪽 클릭 메뉴                                       |

### 마우스 이벤트 객체의 좌표 속성

| 속성                     | 기준                                      |
| ------------------------ | ----------------------------------------- |
| `e.clientX`, `e.clientY` | 브라우저 뷰포트(보이는 문서 영역)         |
| `e.x`, `e.y`             | 교재에서 `clientX`, `clientY`와 함께 설명 |
| `e.screenX`, `e.screenY` | 화면(screen)                              |
| `e.offsetX`, `e.offsetY` | 이벤트 대상 요소 내부 위치                |
| `e.button`               | 누른 마우스 버튼 번호                     |
| `e.wheelDelta`           | 교재의 휠 방향 값: 위 양수, 아래 음수     |

**교재의 `button` 값:** `0` 왼쪽, `1` 가운데, `2` 오른쪽 버튼.

```html
<div onmousemove="where(event)">마우스를 움직이세요</div>
<script>
  function where(e) {
    console.log(e.clientX, e.clientY, e.offsetX, e.offsetY);
  }
</script>
```

### 오른쪽 클릭 메뉴 차단

```javascript
document.oncontextmenu = function () {
  return false;
};
```

## 6. ★ 문서·이미지 로딩과 `onload`

### 문서 로딩 완료

```html
<body onload="init()"></body>
```

```javascript
window.onload = function () {
  console.log("문서 로딩 완료");
};
```

**이유:** DOM 요소가 생성되기 전에 `getElementById()`를 실행하면 요소를 찾지 못할 수 있다. 교재에서는 `onload`에서 초기화 함수를 호출한다.

### 이미지 로딩 완료

```javascript
let img = document.getElementById("myImg");
img.onload = function () {
  console.log(img.width, img.height);
};
img.src = "banana.png";
```

**★ 순서 중요:** `onload` 리스너를 **먼저 설정**하고, 이후 `src`를 변경한다. `src`를 바꾼 직후에는 이미지 로딩이 끝나지 않았을 수 있다.

### `new Image()`

```javascript
let bananaImg = new Image(); // Image 객체 생성, 화면에 자동 표시되지는 않음
bananaImg.src = "banana.png"; // 이미지 로딩
let myImg = document.getElementById("myImg");
myImg.src = bananaImg.src; // 기존 img 요소에 이미지 표시
```

**이미지 배열과 순환**

```javascript
let files = ["a.jpg", "b.jpg", "c.jpg"];
let imgs = [];
for (let i = 0; i < files.length; i++) {
  imgs[i] = new Image();
  imgs[i].src = files[i];
}
let next = 0;
function change(img) {
  img.src = imgs[next].src;
  next = (next + 1) % imgs.length;
}
```

- `% imgs.length`는 배열 끝에 도달하면 인덱스를 다시 0으로 돌리는 연산.
- `sel.options[sel.selectedIndex].value`로 이미지 경로를 얻고, `img.onload`에서 크기를 출력.

## 7. ★ 폼 이벤트와 입력 요소

### `focus` / `blur`

- **포커스(focus)**: 현재 키보드 입력을 받는 요소의 상태.
- `onfocus`: 포커스를 **얻을 때**.
- `onblur`: 포커스를 **잃을 때**.
- `obj.focus()`: 해당 요소에 포커스를 부여하는 메소드.

```html
<input id="name" onblur="checkFilled(this)" />
<script>
  function checkFilled(obj) {
    if (obj.value == "") obj.focus();
  }
</script>
```

### 라디오 버튼과 체크박스

| 구분     | HTML                               | 특징                           |
| -------- | ---------------------------------- | ------------------------------ |
| 라디오   | `<input type="radio" name="city">` | 같은 `name` 그룹에서 하나 선택 |
| 체크박스 | `<input type="checkbox">`          | 여러 개 독립 선택 가능         |

**필수 속성:** `checked` = 선택 여부(boolean), `value` = 값(문자열).

```javascript
let cities = document.getElementsByName("city");
for (let i = 0; i < cities.length; i++) {
  if (cities[i].checked) {
    alert(cities[i].value);
  }
}
```

**체크박스 금액 합산**

```javascript
let sum = 0;
function calc(cBox) {
  if (cBox.checked) sum += parseInt(cBox.value);
  else sum -= parseInt(cBox.value);
  document.getElementById("sumtext").value = sum;
}
```

- `parseInt()`는 문자열을 정수로 변환.
- `onclick="calc(this)"`는 클릭한 체크박스 객체를 함수에 전달.

### select / option / onchange

```html
<select id="fruits" onchange="drawImage()">
  <option value="strawberry.png">딸기</option>
  <option value="banana.png" selected>바나나</option>
  <option value="apple.png">사과</option>
</select>
<img id="fruitimage" alt="선택한 과일" />
<script>
  function drawImage() {
    let sel = document.getElementById("fruits");
    let img = document.getElementById("fruitimage");
    img.src = sel.options[sel.selectedIndex].value;
  }
</script>
```

| 속성                  | 의미                                  |
| --------------------- | ------------------------------------- |
| `selectedIndex`       | 현재 선택된 옵션의 인덱스(0부터 시작) |
| `options`             | `<option>` 요소들의 모음              |
| `options[i].value`    | i번째 옵션의 값                       |
| `options[i].selected` | i번째 옵션 선택 여부                  |
| `onchange`            | 선택이 바뀌면 호출                    |

**폼 초기화·전송**

```html
<form
  onreset="return confirm('초기화할까요?')"
  onsubmit="return confirm('전송할까요?')"
>
  <input type="text" name="memo" />
  <input type="reset" value="초기화" />
  <input type="submit" value="전송" />
</form>
```

- `onreset`과 `onsubmit`은 **`<form>` 태그에 등록**.
- `false`를 반환하면 각각 **초기화 취소 / 제출 취소**.

## 8. ★ 키보드 이벤트

| 이벤트     | 발생 시점                      | 시험 포인트                              |
| ---------- | ------------------------------ | ---------------------------------------- |
| `keydown`  | 키 누르는 순간                 | 일반 키뿐 아니라 Shift, Ctrl 등에도 작동 |
| `keypress` | 교재에서 문자 키 중심으로 설명 | 비문자 키는 호출되지 않는 경우가 있음    |
| `keyup`    | 누른 키를 놓는 순간            | 키 해제 감지                             |

### `e.key` vs `e.code`

```html
<input type="text" onkeydown="whatKeyDown(event)" />
<script>
  function whatKeyDown(e) {
    console.log(e.key); // 키의 의미·값: 예 "a", "ArrowLeft"
    console.log(e.code); // 물리적 키 위치 코드: 예 "KeyA"
  }
</script>
```

**화살표 키 이름:** `"ArrowUp"`, `"ArrowDown"`, `"ArrowLeft"`, `"ArrowRight"`.

### 3×3 표에서 화살표 키로 셀 이동

```javascript
let index = 0; // 0~8
window.onkeydown = function (e) {
  switch (e.key) {
    case "ArrowDown":
      if (index >= 6) return;
      index += 3;
      break;
    case "ArrowUp":
      if (index < 3) return;
      index -= 3;
      break;
    case "ArrowLeft":
      if (index % 3 === 0) return;
      index--;
      break;
    case "ArrowRight":
      if (index % 3 === 2) return;
      index++;
      break;
    default:
      return;
  }
};
```

- 아래/위 = 인덱스 `+3` / `-3`
- 왼쪽/오른쪽 = `-1` / `+1`
- `% 3`으로 현재 열 위치 확인.
- 위 코드는 **이동 계산만 요약**한 것. 교재 완성 예제는 이동 전·후 셀의 `style.backgroundColor`를 바꾼다.

## 9. 코드 단어·표현 암기 사전

| 코드                                  | 의미                                        | 기억할 예시               |
| ------------------------------------- | ------------------------------------------- | ------------------------- |
| `document.getElementById("id")`       | ID로 요소 1개 찾기                          | `getElementById("p")`     |
| `document.getElementsByName("x")`     | name이 같은 요소들 찾기                     | 라디오 그룹               |
| `document.getElementsByTagName("td")` | 태그 이름으로 요소들 찾기                   | 표의 모든 셀              |
| `obj.onclick = f`                     | 클릭 리스너 함수 등록                       | 괄호 없음                 |
| `addEventListener("click", f)`        | 클릭 이벤트 리스너 추가                     | 이벤트 이름에 `on` 없음   |
| `this`                                | 일반 함수 리스너에서 이벤트를 처리하는 요소 | `this.style...`           |
| `event` / `e`                         | 이벤트 객체                                 | `e.type`                  |
| `innerHTML`                           | 요소 내부 HTML 내용 읽기·수정               | `div.innerHTML = "완료"`  |
| `value`                               | 입력 요소의 값                              | `input.value`             |
| `checked`                             | 체크 상태                                   | `checkbox.checked`        |
| `selectedIndex`                       | 선택된 옵션 인덱스                          | `sel.selectedIndex`       |
| `options`                             | select의 옵션 모음                          | `sel.options[i]`          |
| `src`                                 | 이미지 경로                                 | `img.src = "a.png"`       |
| `onload`                              | 로딩 완료 처리                              | `window.onload = ...`     |
| `focus()`                             | 포커스 부여                                 | `input.focus()`           |
| `parseInt()`                          | 문자열을 정수로 변환                        | `parseInt("100")`         |
| `Math`                                | 이 PDF의 핵심 범위는 아님                   | 이벤트 처리와 혼동 금지   |
| `return false`                        | 교재의 HTML 이벤트 처리에서 기본 행동 취소  | `onclick="return false"`  |
| `preventDefault()`                    | 기본 동작 취소                              | `e.preventDefault()`      |
| `stopPropagation()`                   | 이벤트 전파 중단                            | `e.stopPropagation()`     |
| `tagName`                             | 요소의 태그 이름                            | `e.currentTarget.tagName` |
| `style.fontStyle`                     | 글꼴 스타일 변경                            | `"italic"`                |
| `style.borderWidth`                   | 테두리 두께 변경                            | `"3px"`                   |
| `style.backgroundColor`               | 배경색 변경                                 | `"orchid"`                |

## 10. 혼동하기 쉬운 것 한눈에 비교

| A                  | B                                       | 차이                                   |
| ------------------ | --------------------------------------- | -------------------------------------- |
| `click`            | `onclick`                               | 이벤트 이름 / 이벤트 리스너 속성       |
| `f`                | `f()`                                   | 함수 참조 / 함수 실행                  |
| `target`           | `currentTarget`                         | 실제 발생 요소 / 현재 리스너 실행 요소 |
| `preventDefault()` | `stopPropagation()`                     | 기본 동작 취소 / 전파 중단             |
| `true`             | `false` (`addEventListener` 3번째 인수) | 캡처 / 버블                            |
| `mouseover`        | `mouseenter`                            | 자식 경계의 영향·버블링 차이           |
| `mouseout`         | `mouseleave`                            | 자식 경계의 영향·버블링 차이           |

| `innerHTML`        | `value`                                 | HTML 내용 / 입력 컨트롤 값             |
| `window.onload`    | `img.onload`                            | 문서 로딩 완료 / 이미지 로딩 완료      |

## 11. 시험 대비 빈칸·단답형 자가 점검

1. 이벤트를 처리하는 JavaScript 코드를 무엇이라 하는가? → **이벤트 리스너**
2. `addEventListener()`의 첫 번째 인수에 `"onclick"`을 넣는가? → **아니오, `"click"`**
3. `p.onmouseover = over();`의 문제는? → **등록 전에 함수를 실행함**
4. 실제 이벤트 발생 요소를 가리키는 속성은? → **`target`**
5. 현재 리스너가 실행되는 요소를 가리키는 속성은? → **`currentTarget`**
6. 링크의 이동을 막는 메소드는? → **`preventDefault()`**
7. 이벤트가 부모로 전파되는 것을 막는 메소드는? → **`stopPropagation()`**
8. `addEventListener("click", f, true)`의 단계는? → **캡처**
9. 세 번째 인수를 생략하면? → **`false`, 버블 리스너**
10. 마우스 버튼을 누르는 순간 발생하는 이벤트는? → **`mousedown`**
11. 브라우저 표시 영역 기준 마우스 좌표는? → **`clientX`, `clientY`**
12. 문서가 완전히 로딩되었을 때 실행할 리스너는? → **`onload`**
13. 이미지의 크기를 로딩 완료 후 확인하려면? → **이미지 `onload` 안에서 확인**
14. 선택된 라디오 버튼을 확인하는 속성은? → **`checked`**
15. `select`에서 현재 선택된 항목의 인덱스는? → **`selectedIndex`**
16. 선택된 옵션의 값을 읽는 표현은? → **`sel.options[sel.selectedIndex].value`**
17. 포커스를 잃을 때 발생하는 이벤트는? → **`blur`**
18. 누른 키를 놓을 때 발생하는 이벤트는? → **`keyup`**
19. 눌린 키의 의미를 나타내는 속성은? → **`e.key`**
20. 폼 제출을 취소하려면? → **`onsubmit`에서 `false` 반환 또는 `preventDefault()`**
