배치 기능의 CSS3 프로퍼티

- display
- position
- left, right, top, bottom
- float
- z-index
- visibility
- overflow

1. display: 박스의 유형 제어
   - display: box
     - 블록 박스는 새 라인에서 시작.  
       왼쪽에서 오른쪽 끝까지 통째 점유
   - display: inline
     - 인라인 박스는 블록 안에 배치  
       옆에 다른 태그 배치 가능
   - display: inline-box
     - 박스 속성과 인라인 속성 둘 다 가짐

2. position: 박스의 배치
   - position: static (디폴트)
     - 정적배치
   - position: relative
     - 상대배치
   - position: absolute
     - 절대배치
   - position: fixed
     - 고정배치
   - float: left 혹은 float: right
     - 유동배치
   - position 프로퍼티의 태그 위치 지정 방법
     - top, bottom, left, right 프로퍼티로 지정

3. z-index

4. visibility: hidden;
   - 공간은 차지하지만, 텍스트는 보이지 않음.

5. CSS로 리스트 꾸미기
   1. list-style-type
      - 아이템 마커 타입 지정
        > list=style-type:  
        > disc | armenian | circle | cjk-idegraphic | decimal | georgian | lower-alpha | lower=roman | square | upper=alpha | upper=roman | none
   2. list-style-image
      - 아이템 마커 이미지 지정
   3. list-style-position
      - 아이템 마커의 출력 위치 지정(아이템 영역 내 혹은 영역 바깥)
        > list-style-position:  
        > inside | outside
   4. list-style
      - 앞의 3개 프로퍼티 값을 한 번에 지정하는 단축 프로퍼티

6. CSS 표 꾸미기
   1. border: 표 테두리 제어
      - border: 표 테두리
      - border-collapse: collapse; //중복된 테두리 합치기
   2. width, height: 셀 크기 제어
   3. 셀 여백 및 정렬
      - padding: 여백
      - text-align: 정렬(eft, center, right)

7. 폼 꾸미기
   - input[type=text]
     - input[type=text] {color: red;}
       > > 폼 요소의 글자 색 지정
     - input[type=text] {  
       border : 2px solid skyblue;  
       border-radius : 5px;  
       }
       > 2px 두께의 둥근 모서리 테두리
   - 폼 요소에 마우스 처리
     - :hover - 마우스가 올라올 때
     - :focus - 포커스(클릭)를 받을 때

8. CSS3로 태그에 동적 변화 만들기
   - 3가지 기법 지원
     - 애니메이션(animation)
     - 전환(transition)
     - 변환(transform)  
       <br>
       1. 애니메이션
          1. @keyframes으로 HTML 태그의 시간별 모양 변화

          ***

          @keyframes name {  
           시간비율 {스타일; 스타일;}  
           . . .  
           시간비율 {스타일; 스타일;}  
           }

          ***
          2. 애니메이션 스타일 시트 작성
          - animation-name: 애니메이션 이름;
            - @keyframes의 name 지정
          - animation-duration: 시간;
            - 1회 애니메이션 시간
          - animation-iteration-count: 애니메이션 반복 횟수;
            - 숫자로도 가능, infinite로 무한 반복

       2. 전환: HTML 태그의 색이나 모양, 위치 등이 서서히 변하는 효과
          - transition 프로퍼티 이용
            - trainsition: font-size 5s;
              - font-size = 전환 프로퍼티
              - 5s = 전환 시간
       3. 변환: 텍스트나 이미지를 회전, 확대 다양한 기하학적인 모양으로 출력
          - 위치 이동
            - translate(x,y)
            - translateX(n)
            - translateY(n)
          - 확대/축소
            - sclae(W,H)
            - scaleX(n)
            - scaleY(n)
          - 회전
            - rotate(angle)
          - 기울임
            - skew(x-angle, y-angle)
            - skewX(angle)
            - skewY(angle)
