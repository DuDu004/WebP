인터넷 속의 컴퓨터, 클라우드 컴퓨팅

언제 어디서나 데이터와 프로그램을 사용할 수 있게 만든 핵심 컴퓨터 기술

메인 소개 문구
우리는 사진을 저장하고, 동영상을 시청하며, 온라인 문서를 친구들과 함께 편집합니다.
이러한 활동의 공통점은 데이터와 프로그램이 내 컴퓨터가 아닌 인터넷에 연결된 서버에서 처리된다는 것입니다.
이처럼 인터넷을 통해 컴퓨팅 자원을 빌려 사용하는 기술을 클라우드 컴퓨팅이라고 합니다.

클라우드 컴퓨팅이란?

    클라우드 컴퓨팅은 서버, 저장 공간, 데이터베이스, 소프트웨어와 같은 컴퓨터 자원을 인터넷을 통해 제공하는 기술입니다. 과거에는 프로그램을 사용하려면 개인 컴퓨터에 직접 설치해야 했으며, 파일도 컴퓨터의 하드디스크에 저장해야 했습니다. 하지만 클라우드 컴퓨팅을 이용하면 인터넷에 접속하는 것만으로 필요한 프로그램과 데이터를 사용할 수 있습니다.
    예를 들어 Google Drive에 파일을 저장하면 학교 컴퓨터, 집의 노트북, 스마트폰 등 다양한 기기에서 같은 파일을 열어 볼 수 있습니다. 파일이 특정 기기에만 저장된 것이 아니라 클라우드 서버에 저장되어 있기 때문입니다.


왜 ‘클라우드’라고 부를까?


    컴퓨터 네트워크를 설명하는 그림에서는 복잡한 인터넷 구조를 구름 모양으로 간단하게 표현하는 경우가 많았습니다. 사용자는 데이터가 정확히 어느 서버에 저장되어 있는지 몰라도 인터넷을 통해 서비스를 이용할 수 있습니다. 이러한 특징 때문에 인터넷을 통해 제공되는 컴퓨터 자원과 서비스를 클라우드, 즉 ‘구름’이라고 부르게 되었습니다.


클라우드 컴퓨팅의 역사

시기 주요 내용
1960년대    여러 사용자가 하나의 대형 컴퓨터를 함께 사용하는 ‘시분할 시스템’이 등장했습니다. 클라우드 컴퓨팅의 초기 개념으로 볼 수 있습니다.
1970년대    하나의 물리적 컴퓨터를 여러 개의 가상 컴퓨터처럼 사용하는 가상화 기술이 발전했습니다.
1990년대    인터넷이 대중화되면서 네트워크를 통해 프로그램과 서비스를 제공할 수 있는 환경이 만들어졌습니다.
1999년대    Salesforce가 인터넷을 통해 고객 관리 소프트웨어를 제공하면서 서비스형 소프트웨어가 널리 알려지기 시작했습니다.
2000년대    Amazon, Google, Microsoft 등의 기업이 저장 공간과 서버를 인터넷으로 제공하기 시작했습니다.
2010년대    스마트폰과 스트리밍 서비스가 성장하면서 클라우드 컴퓨팅이 일상생활과 기업 활동 전반에 활용되었습니다.
현재    인공지능, 빅데이터, 사물인터넷, 온라인 게임 등 다양한 분야에서 클라우드가 핵심 기반 기술로 사용되고 있습니다.


클라우드 서비스의 종류


  1. SaaS: 서비스형 소프트웨어

    2. 사용자가 프로그램을 직접 설치하지 않고 인터넷을 통해 이용하는 방식입니다.

    주요 예시
    • Google Docs
    • Microsoft 365
    • Zoom
    • Slack

    Google Docs를 사용하면 웹 브라우저에서 문서를 작성하고 다른 사람과 실시간으로 편집할 수 있습니다.

  2. PaaS: 서비스형 플랫폼

    3. 개발자가 프로그램을 만들고 실행할 수 있는 환경을 제공하는 방식입니다. 개발자는 서버와 운영체제를 직접 관리하지 않고 애플리케이션 개발에 집중할 수 있습니다.

    주요 예시
    • Google App Engine
    • Microsoft Azure App Service
    • Heroku

  3. IaaS: 서비스형 인프라

    4. 서버, 저장 공간, 네트워크와 같은 컴퓨터 기반 시설을 인터넷으로 빌려 사용하는 방식입니다.

    주요 예시
    • Amazon Web Services
    • Microsoft Azure
    • Google Cloud
    • 네이버 클라우드 플랫폼

    기업은 필요한 만큼 서버를 빌리고 사용량에 따라 비용을 지불할 수 있습니다.


생활 속 클라우드 컴퓨팅의 예시

  • 온라인 파일 저장

    • Google Drive, Dropbox, Microsoft OneDrive와 같은 서비스는 사진과 문서를 클라우드 서버에 저장합니다. 기기가 고장 나더라도 서버에 저장된 파일은 다시 내려받을 수 있습니다.

  • 동영상 및 음악 스트리밍

    • YouTube, Netflix, Spotify와 같은 서비스는 동영상이나 음악을 사용자의 기기에 모두 저장하지 않습니다. 사용자가 선택한 콘텐츠를 클라우드 서버에서 실시간으로 전송합니다.

  • 온라인 게임

    • 일부 온라인 게임은 게임 데이터를 클라우드 서버에 저장합니다. 클라우드 게임에서는 게임 실행에 필요한 복잡한 연산도 서버가 처리하고 사용자의 화면에는 영상 형태로 전달합니다.

  • 실시간 공동 작업

    • 여러 사람이 하나의 온라인 문서를 동시에 수정할 수 있습니다. 한 사람이 내용을 변경하면 그 결과가 클라우드 서버에 저장되고 다른 사용자에게 즉시 반영됩니다.

  • 스마트폰 데이터 백업

    • 스마트폰의 사진, 연락처, 일정 등을 클라우드에 백업할 수 있습니다. 새로운 스마트폰으로 교체하더라도 기존 데이터를 쉽게 복원할 수 있습니다.

  • 인공지능 서비스

    • 대규모 인공지능은 많은 데이터를 처리하고 복잡한 계산을 수행해야 합니다. 클라우드의 강력한 서버와 GPU를 이용하면 개인 컴퓨터만으로 실행하기 어려운 인공지능 서비스도 제공할 수 있습니다.
