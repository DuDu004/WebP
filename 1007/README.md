# 명품 웹 프로그래밍 6장 핵심 요약 --- JavaScript

## 1. JavaScript란?

-   HTML 페이지에 동작을 추가하는 스크립트 언어입니다.
-   사용자 입력 처리, 계산, HTML 내용 및 CSS 변경 등에 사용합니다.
-   브라우저에서 실행되며 별도 컴파일 과정이 필요하지 않습니다.

## 2. JavaScript 코드 작성 위치

``` html
<!-- HTML 요소의 이벤트 속성 -->
<button onclick="alert('안녕하세요')">클릭</button>

<!-- HTML 안의 script 태그 -->
<script>
  let sum = 1 + 2;
  document.write(sum);
</script>

<!-- 외부 .js 파일 불러오기 -->
<script src="script.js"></script>
```

-   외부 파일에는 `<script>` 태그 없이 JavaScript 코드만 작성.
-   `this`는 이벤트가 발생한 현재 HTML 요소를 가리킬 때 사용.

## 3. 출력과 사용자 입력

  ----------------------------------------------------------------------------
  함수                         기능                    반환값/특징
  ---------------------------- ----------------------- -----------------------
  `document.write()`           웹 페이지에 HTML 내용   HTML 태그도 해석
                               출력                    

  `alert("메시지")`            경고창 표시             반환값을 활용하지 않음

  `prompt("질문", "기본값")`   문자열 입력창 표시      입력 문자열 또는 취소
                                                       시 `null`

  `confirm("질문")`            확인/취소 창 표시       확인은 `true`, 취소는
                                                       `false`
  ----------------------------------------------------------------------------

`prompt()`의 결과는 문자열이므로 숫자로 계산하려면 `parseInt()` 등을
이용.

## 4. 변수, 상수, 자료형

``` javascript
let score = 90;       // 변수 선언
const MAX = 100;      // 상수: 값을 다시 대입할 수 없음
let name = "Kim";     // 문자열
let passed = true;    // 논리값
```

-   주요 자료형: 숫자, 문자열, 논리값(`true`/`false`), 객체 참조,
    `null`.
-   `let`: 변수 선언. 같은 범위에서 재선언할 수 없고, `{ }` 블록 범위를
    가짐.
-   `const`: 재대입할 수 없는 상수이며 블록 범위를 가짐.
-   `var`: 오래된 변수 선언 방식으로, 재선언과 범위 관련 실수가 생길 수
    있어 자료에서는 `let` 사용을 권장.
-   식별자는 대소문자를 구분하며 숫자로 시작할 수 없다. 예약어(`if`,
    `for` 등)는 이름으로 사용할 수 없다.
-   주석: `// 한 줄`, `/* 여러 줄 */`

## 5. 자주 쓰는 연산자

  종류   연산자                      예
  ------ --------------------------- -------------------------------------
  산술   `+ - * / %`                 `7 % 3`은 `1`
  증감   `++ --`                     `i++`, `--n`
  대입   `= += -= *= /= %=`          `sum += i`는 `sum = sum + i`와 같음
  비교   `> < >= <= == != === !==`   조건식의 참/거짓 판단
  논리   `&& || !`                   AND, OR, NOT

-   `++a`(전위)는 먼저 증가한 값을 사용하고, `a++`(후위)는 기존 값을
    먼저 사용한 뒤 증가.
-   `==`는 값 중심으로 비교하며, `===`는 자료형까지 엄격하게 비교.
-   연산 우선순위가 헷갈리면 괄호를 사용.

## 6. 조건문

``` javascript
if (score >= 90) {
  grade = "A";
} else if (score >= 80) {
  grade = "B";
} else {
  grade = "F";
}
```

여러 값 중 하나를 선택할 때는 `switch`를 사용할 수 있다.

``` javascript
switch (menu) {
  case "커피":
    price = 2000;
    break;
  case "차":
    price = 1500;
    break;
  default:
    price = 0;
}
```

-   `break`는 `switch`를 빠져나옵니다. 생략하면 다음 `case` 코드까지
    계속 실행될 수 있다.
-   `default`는 일치하는 `case`가 없을 때 실행.

## 7. 반복문

``` javascript
for (let i = 0; i < 5; i++) {
  document.write(i);
}

let n = 0;
while (n < 5) {
  n++;
}

do {
  n++;
} while (n < 5);
```

-   `for`: 초기식, 반복 조건, 반복 후 작업을 한곳에 작성.
-   `while`: 조건이 참인 동안 반복. 조건이 처음부터 거짓이면 한
    번도 실행하지 않을 수 있다.
-   `do-while`: 본문을 먼저 실행하므로 최소 한 번은 실행.
-   `break`: 가장 가까운 반복문을 종료.
-   `continue`: 현재 반복의 남은 부분을 건너뛰고 다음 반복으로
    넘어간다.

## 8. 함수

``` javascript
function adder(a, b) {
  return a + b;
}

let result = adder(10, 20); // 30
```

-   `function`으로 선언하고, 이름과 매개변수를 정합니다.
-   호출할 때 인자를 전달하며, `return`은 결과를 반환하고 함수 실행을
    끝낸다.

## 9. 알아둘 전역 함수

``` javascript
parseInt("32");          // 정수 32
isNaN("hello");          // true: 숫자가 아님
eval("2 * 3 + 4");       // 문자열을 JavaScript 식으로 계산
```

-   `parseInt()`: 문자열 등을 정수로 변환합니다. 변환할 수 없으면
    `NaN`이 될 수 있다.
-   `isNaN()`: 값이 숫자로 취급될 수 없는지 확인한다.
-   `eval()`: 문자열을 코드로 실행합니다. 개념은 알아두되, 일반적인
    코딩에서는 사용을 피하는 편이 안전.
